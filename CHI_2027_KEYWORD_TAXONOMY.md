# Keywords

Authors should imagine that the list of keywords is preceded by the following phrase: **"A reviewer judging my work should have expertise related to..."**

Use these keywords to tag the **expertise needed to assess your contribution**, rather than to describe your submission. Use the following rules:

- **Domain** (2-6)
- **Method / Approach** (1-2)
- **Users** (0-2, only if a specific population is the focus)
- **Primary Contribution** (exactly 1)

These tags are used to identify reviewers for your submission matched against their self-rated expertise.

Not sure which keywords fit? Use the [keyword finder tool](https://hcitang.github.io/apps/chi2027-keyword-finder/) to browse and search the full list.
