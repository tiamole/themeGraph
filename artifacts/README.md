# Publication Artifacts

Generate from the workspace root with:

```powershell
.\.venv\Scripts\python.exe scripts/build_publication_artifacts.py
```

The first author reports collecting the combined Glassdoor and SimplyHired dataset in June 2023. Public release under CC BY 4.0 is planned, but no public deposit URL is recorded yet. Raw job text is excluded from these artifacts. See `manifest.json` for source and output hashes.
